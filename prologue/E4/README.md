| Look | 参考 | 组件 |
|---|---|---|
| R1 暖金光尘 + 光环 | 1 | 15 万光尘（胸口最亮、右侧飘散）+ 身后细光环 |
| R2 电光蓝光尘 + 光环 | 2 | 同 R1，hue=1 |
| R3 光谱光柱贯穿 | 3 | 只留轮廓的金色光尘（rimOnly）+ 锯齿光谱光柱 |

- `preview_E4_2.html`：浏览器打开 = 交互（R1–R7 按钮、拖拽旋转、`#R5` 锚点）；Playwright 打开 = `seek(t)` 渲染（每个 look 4 s）
